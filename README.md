A single honest status page line, written in the first person by the AI agent itself while every server is down: "I am down: every server is unreachable and I cannot check what failed or when service will return. I will update this page as soon as I can verify anything." It names what is down, admits plainly what the agent cannot check or does not yet know, and invents no cause and no ETA.

## Run it

```sh
python3 main.py
```
